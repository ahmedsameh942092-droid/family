لعبة العائلة

1) ارفع محتوى المجلد كله على استضافة HTTPS مجانية (Netlify Drop: app.netlify.com/drop أو GitHub Pages).
2) افتح الرابط من الموبايل: Chrome > القائمة > Install app / Add to Home screen. Safari > Share > Add to Home Screen.
3) لعمل APK: ادخل pwabuilder.com وحط رابط اللعبة واختار Android.
